# Beiträge

Danke fürs Interesse! Kurz und ehrlich:

- **Pull Requests nehme ich nicht an.** Diktat läuft als Bedienungshilfe. Es kann Bildschirminhalte lesen und in
  fremde Apps schreiben. Jeder fremde Code wäre ein Sicherheitsrisiko für alle, die die App nutzen. Pull Requests
  schließe ich deshalb ungelesen.
- **Forken ist ausdrücklich erwünscht.** Pass Diktat für dich an, die MIT-Lizenz erlaubt das.
- **Issues** mit einem klaren Fehlerbild lese ich gern. Ich verspreche aber keine Antwort und keinen Fix. Das ist
  ein privates Projekt.
- **Sicherheitslücken** bitte nicht öffentlich als Issue melden, sondern über
  [GitHubs private Meldung](https://github.com/hwalde/diktat-android/security/advisories/new).
